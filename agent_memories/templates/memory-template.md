# Descriptive Topic Title

- Kind: investigation | plan | decision | handoff
- Status: draft | active | blocked | resolved | superseded
- Created: YYYY-MM-DD
- Last verified: YYYY-MM-DD
- Scope: affected repositories and components
- Evidence baseline: repository, branch/commit, and relevant local changes
- Related: links to canonical notes, issues, or replacement notes

## Context and objective

State the problem, intended outcome, and boundaries in a few sentences.

## Verified findings

List confirmed observations with meta-root-relative file paths and source symbols, commit IDs, or reproducible sanitized evidence. Separate historical observations from current invariants.

## Hypotheses and open questions

Label unverified explanations and state what would confirm or reject them.

## Decision or implementation plan

Record the chosen approach, rationale, compatibility/version impact, and alternatives that explain a meaningful tradeoff. Mark proposals as pending until accepted. Include dependency, migration, and pointer order where relevant.

## Verification

Record each command's working directory, relevant environment/tool versions, actual result, and limitations. Explicitly list unrun checks. Never include credentials, raw tokens, or production personal data.

## Handoff and next actions

List concrete remaining work, blockers, responsible repository/files, final published commit references if available, and the checks needed for completion. Link any canonical note updated with durable findings.
